# fitness-lifestyle-prediction
🚀 Fitness &amp; Lifestyle Prediction Model 🏋️‍♂️🥗 
This machine learning project predicts whether an individual is healthy or not based on various physical and lifestyle attributes such as diet preferences, activity levels, sleep habits, and career type.

🔧 Installation & Setup
## Installation
1. Clone the repository:
git clone https://github.com/your-username/fitness-lifestyle-prediction.git

2. Install dependencies:
pip install -r requirements.txt

3. Open the Jupyter notebook or run it in Google Colab.
   
📊 Dataset Details
Explain the dataset:
6,000 entries with features like physical fitness, diet, sleep habits, career, etc.
Target variable: is_healthy (1 = Healthy, 0 = Not Healthy)

🤖 Machine Learning Models Used
Support Vector Machine (SVM)
Random Forest Classifier

📈 Accuracy
SVM Accuracy: 98.74%
Random Forest Accuracy: 97.90%
